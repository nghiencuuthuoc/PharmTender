# End-User Guide: Searching Tender Award Results by Company in PharmApp / PharmTender

**Example company:** Stellapharm  
**Systems:**  
- https://pharmapp.dev/Pharm_Tender_VN  
- https://pharmapp.vn/Pharm_Tender_VN  

**Document purpose:** This guide helps end users log in to PharmApp / PharmTender and search pharmaceutical tender award results by company name, using Stellapharm as an example.

---

## 1. Overview

The **Drug Tender Result Search** function in PharmApp / PharmTender allows users to quickly search awarded tender data by:

- Company name or manufacturer name
- Drug name
- Active ingredient
- Strength
- Dosage form
- Route of administration
- Unit price
- Quantity
- Manufacturing site
- Country of manufacture
- Data source group, such as modern medicines, herbal medicines, medical devices, or other goods

This function is useful for market analysis, price reference, competitor tracking, product portfolio review, and pharmaceutical tender monitoring.

---

## 2. Accessing the System

Open a supported browser such as Google Chrome, Microsoft Edge, or Firefox.

Go to one of the following websites:

```text
https://pharmapp.dev/Pharm_Tender_VN
```

or

```text
https://pharmapp.vn/Pharm_Tender_VN
```

Use the account provided by the system administrator.

---

## 3. Logging In

1. Open the PharmApp website.
2. Enter your **username**.
3. Enter your **password**.
4. Click **Login**.
5. After successful login, the PharmApp workspace interface will be displayed.
6. To exit the system, click **Logout** on the left sidebar.

> Note: Do not share your account with other users. If you cannot log in, contact the system administrator.

---

## 4. Selecting the Correct Workspace and Module

After logging in, use the left sidebar.

### Step 1: Select Workspace

Choose:

```text
PharmApp
```

### Step 2: Select Function Group

Choose the medical tender workspace or function group:

```text
Đấu Thầu Y Tế
```

or, in English interface:

```text
Medical Tender
```

### Step 3: Select Search Module

For tender result lookup, select one of the following modules:

```text
MSC Tender Search Export Excel
```

or

```text
MSC Tender Search
```

Recommended module:

```text
MSC Tender Search Export Excel
```

This module is preferred when you want to search and export results to Excel.

---

## 5. Searching Tender Results for a Company

This section uses **Stellapharm** as an example.

### Step 1: Select Language

At the top of the page, choose:

- **VN** for Vietnamese
- **EN** for English

For English-speaking users, select:

```text
EN
```

---

### Step 2: Select Function

In the **Function** section, select:

```text
Search
```

---

### Step 3: Choose Data Source

In the **Search Source** section, select the appropriate data source.

For finished pharmaceutical products, choose:

```text
Modern medicines
```

In Vietnamese interface, this may appear as:

```text
Thuốc tân dược
```

Other available sources may include:

- Herbal medicines
- Traditional medicine materials
- Medical devices and supplies
- Other goods
- All sources

If you are not sure which source contains the data, choose:

```text
All sources
```

---

### Step 4: Enter the Company Keyword

In the **Keyword** field, enter the company name or part of the company name.

Example:

```text
Stellapharm
```

You may also search with a shorter keyword:

```text
Stella
```

Using a shorter keyword can help find records where the company name is written in different formats.

---

### Step 5: Run the Search

Click:

```text
Search
```

If supported by the system, you may also press:

```text
Ctrl + Enter
```

to submit the search form.

---

## 6. Understanding the Search Results

After the search is completed, the system displays the **Results** section.

The summary area may include:

- Number of results
- Lowest price
- Median price
- Highest price
- Search keyword

Example when searching for Stellapharm:

```text
Keyword: Stellapharm
Number of results: 300
Lowest price: 330
Median price: about 2,100
Highest price: depends on the matched dataset
```

The numbers may vary depending on the selected source, filters, and database version.

---

## 7. Reading the Result Table

The result table usually contains columns similar to the following:

| Column | Meaning |
|---|---|
| Data group | Type of data, such as modern medicines |
| Drug name | Product or brand name |
| Active ingredient | Main active pharmaceutical ingredient |
| Strength / specification | Drug strength or product specification |
| Route of administration | Oral, injection, topical, etc. |
| Dosage form / description | Tablet, capsule, powder, vial, etc. |
| Unit | Unit of measure, such as tablet, bottle, vial, pack |
| Quantity | Awarded quantity |
| Unit price | Awarded tender unit price |
| Manufacturing site | Manufacturer or manufacturing facility |
| Country of manufacture | Manufacturing country |

Example products that may appear when searching for Stellapharm include:

- Alumastad
- Metformin Stella 850mg
- Partamol Tab.
- Partamol 500 Cap
- Acyclovir Stella 800mg
- Pracetam 1200

Actual results depend on the latest available tender dataset.

---

## 8. Using Optional Filters

If the result list is too large, open:

```text
Optional filters
```

Depending on the module version, you may be able to filter by:

- Drug name
- Active ingredient
- Strength
- Route of administration
- Dosage form
- Unit price range
- Manufacturer
- Country of manufacture
- Data group

After selecting filters, click **Search** again to refresh the results.

---

## 9. Exporting Results to Excel

If you are using the **MSC Tender Search Export Excel** module, you may export the result table.

General steps:

1. Complete the search.
2. Review the result table.
3. Click **Export Excel**, **Download Excel**, or **Tải Excel**, depending on the interface language.
4. Open the downloaded Excel file.
5. Use Excel filters, sorting, pivot tables, or charts for further analysis.

If you do not see the export option, make sure you selected:

```text
MSC Tender Search Export Excel
```

from the left sidebar.

---

## 10. Recommended Keyword Strategy

Company names may be written differently in tender datasets. To improve search coverage, try several keyword variations.

For Stellapharm, you may try:

```text
Stellapharm
```

```text
Stella
```

```text
Công ty TNHH Liên doanh Stellapharm
```

```text
Stellapharm - Chi nhánh 1
```

Recommended approach:

1. Start with the full company name.
2. If results are limited, try a shorter keyword.
3. If results are too broad, use optional filters.
4. Export results to Excel for deeper review.

---

## 11. Common Issues and Solutions

| Issue | Suggested Solution |
|---|---|
| No result is found | Try a shorter keyword, such as `Stella` instead of `Stellapharm` |
| Too many results | Use optional filters to narrow the search |
| Cannot find the tender module | Check that the selected workspace is PharmApp and the selected function group is Medical Tender / Đấu Thầu Y Tế |
| Login failed | Check username and password, then contact the administrator |
| Page loads slowly | Wait a few seconds, refresh the page, or check the internet connection |
| Cannot export to Excel | Switch to the `MSC Tender Search Export Excel` module |
